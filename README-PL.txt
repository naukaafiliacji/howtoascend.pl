LOKALNA KOPIA howtoascend.pl

Windows:
1. Rozpakuj całe archiwum ZIP.
2. Kliknij dwukrotnie plik START-WINDOWS.bat.
3. Strona otworzy się pod adresem http://localhost:8000/
4. Nie zamykaj czarnego okna, dopóki korzystasz ze strony.

Linux / macOS:
1. Otwórz terminal w tym katalogu.
2. Uruchom: bash START-LINUX-MAC.sh
3. Otwórz http://localhost:8000/

Ważne:
- Nie otwieraj index.html bezpośrednio przez file://. Moduły JavaScript wymagają
  prostego lokalnego serwera, który uruchamiają dołączone skrypty.
- Linki prowadzące do usług zewnętrznych (np. Calendly) nadal wymagają internetu.
- Kod, obrazy, filmy, fonty, moduły Framera i zawartość bloga są zapisane lokalnie.
